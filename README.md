# Tic-Tac-Toe
Tic-Tac-Toe is a simple two-player game developed using HTML, CSS, and JavaScript. Players take turns marking X and O on a 3×3 grid. The game automatically checks for winning combinations, draws, and allows players to restart the game.  Key Features: - 3×3 interactive game board - Two-player gameplay - Automatic win/draw detection - Restart
