# Tic-Tac-Toe

A complete, modern, and responsive two-player Tic-Tac-Toe web app built with plain HTML, CSS, and JavaScript.

## Features

- Interactive 3×3 game board
- Two-player mode (Player X and Player O)
- Turn-based status updates
- Automatic winner detection
- Draw detection
- Winning cells highlight animation
- New Game button to restart instantly
- Occupied-cell click prevention
- Responsive design for desktop, tablet, and mobile

## Technologies Used

- HTML5
- CSS3
- JavaScript (Vanilla JS)

## How to Run the Project

1. Clone or download this repository.
2. Open `/home/runner/work/Tic-Tac-Toe/Tic-Tac-Toe/index.html` in any modern browser.
3. Start playing.

## Game Rules

1. Player X starts first.
2. Players take turns placing their symbol (X or O) in empty cells.
3. A player wins by placing three of their symbols in a row:
   - Horizontally
   - Vertically
   - Diagonally
4. If all cells are filled and no winning line is formed, the game is a draw.
5. Click **New Game** to restart the match at any time.
